# Čo uvarím z Chilli

Osobná webová appka: zaškrtneš suroviny, ktoré máš doma, a ukáže recepty, ktoré z nich uvaríš.
Recepty sú prepísané z YouTube videí [Chilli Fitness (@chilli_fitness22)](https://www.youtube.com/@chilli_fitness22). Pri každom recepte je odkaz na pôvodné video.

Na iPhone/iPade: otvor v Safari → Zdieľať → Pridať na plochu.
