# Chill s Chilli

Osobná webová appka: zaškrtneš suroviny, ktoré máš doma, a ukáže recepty Chilli Fitness, ktoré z nich uvaríš. Obsahuje aj 2-týždňový jedálniček a nákupný zoznam.
Recepty a hodnoty pochádzajú z verejných príspevkov [Chilli Fitness (@chilli_fitness22)](https://www.instagram.com/chilli_fitness22/) na Instagrame a YouTube. Pri každom recepte je odkaz na originál.

- Hlavná verzia: `/`
- Pôvodná verzia: `/v1/`

Na iPhone/iPade: otvor v Safari → Zdieľať → Pridať na plochu.
